# Habitat Meal Builder (website version)

The client meal planner shown on Habitat Gym's GHL page.

- **Don't edit these files by hand.** Recipes are managed in the Claude version's Coach tools, and Claude publishes updates here.
- `meals.js` is the only file the GHL page loads. It pulls in the app and the recipe file.
- `recipes.enc.js` is encrypted. It can only be opened with the client access code, so the recipes can't be read here.
- Test page: https://jeannie-habitat.github.io/habitat-meals/
